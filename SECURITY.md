# Security

This is a static website plus a list of links. There are no accounts, secrets or user data.

**Report a problem privately** (for example a listed link that now serves malware or phishing, or a vulnerability
in the site or workflows) via GitHub's
[private vulnerability reporting](https://github.com/NikaGeospatial/awesome-office-gg/security/advisories/new).

For a dead or spammy link that is *not* dangerous, a normal issue or PR is fine; see [CONTRIBUTING.md](CONTRIBUTING.md#fixing-dead-games).
